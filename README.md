# pereljon/tap

Personal Homebrew tap.

## Install

```bash
brew tap pereljon/tap
```

## Formulae

| Formula | Description |
|---|---|
| [claude-mux](https://github.com/pereljon/claude-mux) | Multi-session Claude Code manager for tmux |
| [claude-now-context](https://github.com/pereljon/claude-now-context) | Injects current datetime and response duration into every Claude Code prompt |

## Usage

```bash
brew install claude-mux
brew install claude-now-context
```

## Update

```bash
brew update && brew upgrade
```
